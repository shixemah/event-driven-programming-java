# Week 4: Making Swing Applications Interactive (Event Handling)

| Activity | Folder | Run |
|---|---|---|
| 1. First button | `activity1-actionlistener-basics` | `javac FirstButton.java` then `java FirstButton` |
| 2. Listener techniques | `activity2-listener-techniques` | `javac *.java` then `java ListenerDemo` / `java EventSourceDemo` |
| 3. Item + Document listeners | `activity3-item-and-document-listeners` | `javac *.java` then `java ItemListenerDemo` (or `DocumentListenerDemo`, `LiveSearchDemo`) |
| 4. Counter app | `activity4-counter-app` | `javac CounterApp.java` then `java CounterApp` |
| 5. Registration form | `activity5-interactive-form` | `javac RegistrationForm.java` then `java RegistrationForm` |
| 6 (bonus). Mouse + key | `activity7-mouse-and-key` | `javac *.java` then `java DrawingApp` / `java KeyboardMover` |

`screenshots/` holds pictures of each program, taken during real test runs. Each activity folder has a `SelfCheck.md` with the self-check answers.
Compile with `javac -encoding UTF-8 *.java` if the minus sign on the counter does not display.
