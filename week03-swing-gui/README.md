# Week 3: Building GUI Applications with Swing

| Activity | Folder | Run |
|---|---|---|
| 1. First window | `activity1-first-window` | `javac FirstWindow.java` then `java FirstWindow` |
| 2. Component showcase | `activity2-basic-components` | `javac ComponentShowcase.java` then `java ComponentShowcase` |
| 3. Layout managers | `activity3-layout-managers` | `javac *.java` then e.g. `java CombinedLayoutDemo` |
| 4. EDT rule | `activity4-edt-rule` | `javac *.java` then `java FreezeDemo` / `java FixedDemo` |
| 5. Student Portal mockup | `activity5-complete-mockup` | `javac StudentPortal.java` then `java StudentPortal` |

`screenshots/` holds a picture of each running window. Self-check answers are in each activity folder.
