# Activity 2: Self-Check

**Q1. JTextField vs JTextArea?** `JTextField` is single-line input (name, email); `JTextArea` is multi-line (comments, descriptions).

**Q2. Why a ButtonGroup for radio buttons?** It makes the buttons mutually exclusive, so only one can be selected at a time.

**Q3. Why does a JTextArea need a JScrollPane?** `JTextArea` has no built-in scrollbars; wrapping it in a `JScrollPane` adds them when text exceeds the visible area.
