# Week 9: Asynchronous Programming in JavaFX

A Maven project (same structure as Weeks 6 to 8). Run each activity from this folder:

| Activity | Class | Run |
|---|---|---|
| 1. The Freeze (the bad way) | `FreezeDemo` | `mvn clean javafx:run` |
| 2. The Fix (Task + safe UI updates) | `TaskDemo` | `mvn clean javafx:run@task` |
| 3. Live progress (progress bar) | `ProgressDemo` | `mvn clean javafx:run@progress` |
| 4. Service (cancel and restart) | `ServiceDemo` | `mvn clean javafx:run@service` |

Requirements: JDK 17 or newer, Maven, and internet the first time (Maven downloads JavaFX 21).
`screenshots/` holds pictures and console output from real test runs; answers are in `SelfCheck.md`.
